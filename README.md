# Расписание 2576-ЭБ

📅 **Открыть приложение:** https://cdn2041.github.io/raspisanie-MITSO/

Неделя (над чертой / под чертой) переключается автоматически.
После первого открытия работает без интернета.

## Установка на iPhone

### iOS 26 и новее

1. Открой ссылку в **Safari**.
2. Нажми **«•••»** справа внизу, рядом с адресной строкой.
3. Выбери **«Поделиться»**.
4. Пролистай вниз и нажми **«На экран «Домой»»** (если не видно, нажми **«Ещё»**).
5. Проверь, что включено **«Открывать как веб-приложение»**, и нажми **«Добавить»**.

### iOS 16-18

1. Открой ссылку в **Safari**.
2. Нажми **«Поделиться»** (квадрат со стрелкой вверх) на нижней панели.
3. Пролистай меню вниз и выбери **«На экран «Домой»»**.
4. Нажми **«Добавить»** справа вверху.

Если пункта **«На экран «Домой»»** нет в списке, в самом низу меню нажми **«Править действия»** и добавь его.

## Установка на Android

1. Открой ссылку в **Chrome**.
2. Нажми **⋮** справа вверху.
3. Выбери **«Добавить на главный экран»** (или **«Установить приложение»**).
4. Нажми **«Установить»** или **«Добавить»**.

## Если что-то не так

- **Не обновилось расписание:** полностью закрой приложение (смахни из списка открытых) и открой снова. Если не помогло, повтори через пару минут.
- **Сменилась иконка, а на экране старая:** удали иконку с экрана «Домой» и добавь заново. Заметки при этом удалятся.
- Заметки хранятся только на твоём телефоне, другие их не видят.

## Админка (для старосты)

Расписание лежит в файле `schedule.json`. Менять его можно через админку: https://cdn2041.github.io/raspisanie-MITSO/admin.html (или в приложении: шестерёнка → «Админка», кнопка появляется после первого входа).

Что там можно делать:
- **Дни:** заменить, отменить или добавить пару на конкретную дату, выбирая готовую карточку пары через поиск.
- **Неделя:** править постоянное расписание по дате (неделя над или под чертой определяется сама).
- **Сессия:** период сессии, экзамены, зачёты, консультации.
- **Общее:** какая сейчас неделя, последний день занятий, звонки с пятиминутками, справочник «Карточки пар».

После «Сохранить» сайт обновляется сам через 1-2 минуты, у всех расписание подтянется при следующем открытии приложения.

### Как стать админом

**Шаг 1. Аккаунт и доступ (один раз).**
1. Заведи аккаунт на https://github.com (если его нет).
2. Сообщи свой логин владельцу. Владелец открывает репозиторий → **Settings → Collaborators → Add people**, вводит логин и отправляет приглашение.
3. Прими приглашение: оно придёт на почту или висит на https://github.com/notifications.

**Шаг 2. Ключ.**
1. Войди на GitHub со своего аккаунта.
2. Открой админку и нажми **«Создать ключ на GitHub»**, или открой сразу: https://github.com/settings/tokens/new?scopes=public_repo&description=Админка%20расписания%202576-ЭБ
3. GitHub может попросить пароль или код, это нормально.
4. Галочка **public_repo** уже стоит, больше ничего не отмечай. В **Expiration** выбери срок (например, «No expiration», чтобы не создавать ключ заново).
5. Внизу нажми **Generate token**.
6. Скопируй ключ, он начинается с `ghp_`. GitHub показывает его один раз. Если потерял, просто создай новый.

**Шаг 3. Вход.**
1. Вставь ключ в админке и нажми **«Войти»**.
2. Админка проверит ключ: настоящий ли он, есть ли у аккаунта доступ к репозиторию и стоит ли галочка public_repo. Если что-то не так, она напишет, что именно.
3. Ключ хранится только на твоём устройстве. На другом телефоне войди тем же ключом или создай ещё один.

Новые «fine-grained» ключи для соавторов чужого репозитория GitHub пока не поддерживает, поэтому нужен именно classic (кнопка в админке создаёт как раз его).

### Как забрать доступ

Владелец убирает человека в **Settings → Collaborators**. При следующем открытии админки его ключ перестанет подходить, и админка закроется. Сам человек может удалить свой ключ на https://github.com/settings/tokens. Все правки видны в истории коммитов, любую можно откатить.
